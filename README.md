# Бангуми — как поставить на телефон

Это веб-приложение (PWA). Его нужно один раз выложить в интернет (бесплатно), а потом установить на Android из Chrome — оно появится на главном экране как обычное приложение и будет работать без интернета.

## 1. Выложить на GitHub Pages (с компьютера, ~5 минут)

1. Зарегистрируйся на https://github.com (бесплатно).
2. Нажми **New repository**, назови `bangumi`, выбери **Public**, нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**.
4. Перетащи туда **содержимое** папки `bangumi` (файлы `index.html`, `app.js`, `core.js`, `sw.js`, `styles.css`, `manifest.webmanifest` и папку `icons`), нажми **Commit changes**.
5. Открой **Settings → Pages**. В «Source» выбери **Deploy from a branch**, ветка **main**, папка **/ (root)**, нажми **Save**.
6. Через 1–2 минуты появится адрес вида `https://твой-логин.github.io/bangumi/`.

## 2. Установить на Android

1. Открой этот адрес в **Chrome** на телефоне.
2. Нажми **⋮ → Установить приложение** (или «Добавить на главный экран»).
3. Открой Бангуми с главного экрана → вкладка **Профиль** → включи уведомления.

## Жесты

- **Потяни вниз** на любой вкладке, чтобы обновить данные.
- **Зажми** постер или карточку, чтобы открыть быстрое меню: +1 серия, статус, в расписание.
- **Свайп вправо** по строке в «Моём списке» (вид «список») — отметить следующую серию. По пункту плана — поставить галочку.
- **Свайп влево/вправо** по расписанию — соседний день.
- Кнопки стеклянные: полупрозрачные, с размытием и бликом там, где касаешься. Выключаются в **Профиль → Вид**.
- Окна закрываются смахиванием: нижние листы и страница тайтла — вниз, «Быстро в расписание» — влево.

## Карта (Мой список)

Третий вид «Моего списка» — ментальная карта, как в Заметках. Включается кнопкой с веткой в «Моём списке» или в **Профиль → Вид → Мой список → Карта**.

- Двигай карту пальцем, приближай щипком, крути двумя пальцами (возле 0°, 90°, 180° угол прилипает).
- Тап по узлу — кнопки «+1», «Открыть», меню. Двойной тап по тайтлу — сразу страница тайтла. Двойной тап по фону — приблизить.
- Перетащи любой узел — он переедет вместе со своими ветками. «↺» в пузыре возвращает его на место.
- Тап по группе → «Свернуть», чтобы спрятать её ветки.
- Кнопка с палитрой — «Оформление»: раскладка (вправо, влево, в обе стороны, вниз, кругом), группы (статус, дни плана, жанры), вид узлов, линии и их толщина, цвета (по статусу, радуга, цвет обложки, свой цвет), фон (точки, клетка, градиент, звёзды, сияние, обложка — каждый неподвижный или живой), движение линий (поток, дыхание, искры, неон), угол поворота, размер текста и надпись в центре.

## Интерфейсы

Профиль → **Интерфейс**: три разных вида приложения.
- **Кинотеатр** — тёмный, большие постеры, стекло и свечение.
- **Манга** — бумага и тушь, панели с жёсткими тенями, ч/б картинки (зажми постер — появится цвет), линии фокуса, красная печать. Есть светлая и ночная версия.
- **Квест** — пиксельная RPG: рамки, всё движется рывками, серии дают опыт, у тебя есть уровень и звание.

Профиль → Вид → **Плавность**: «Авто» сам включает лёгкий режим на слабых телефонах, «Быстро» убирает размытие и тяжёлые эффекты, «Красиво» включает всё.

## Поделиться → Бангуми

Смотришь серию в Crunchyroll, на AnimeOn, AnimeGO или где угодно — нажми «Поделиться» и выбери **Бангуми**. Он сам найдёт название и номер серии, подберёт тайтл из твоего списка или из базы и предложит «Отметить EP 5» одним касанием. Удачные совпадения запоминаются. Ссылку можно вставить и вручную: **Поиск → Ссылка на серию**.

Если Бангуми не появляется в меню «Поделиться», удали его с главного экрана и установи заново из Chrome (сначала сохрани резервную копию).

## Быстро в расписание

- Внутри Бангуми: два быстрых свайпа вправо от левого края экрана открывают окошко «Быстро в расписание». Выключается в **Профиль → Вид**.
- С главного экрана: зажми иконку Бангуми → **«Быстро в расписание»**. Этот пункт можно перетащить на рабочий стол отдельной кнопкой.

## Если нужен именно APK-файл

Зайди на https://www.pwabuilder.com, вставь свой адрес с GitHub Pages, выбери **Android** — сайт соберёт APK из этого же приложения.

## Важно

- Список хранится только на телефоне. Время от времени делай **Профиль → Резервная копия → Сохранить**.
- Даты выхода серий и обложки берутся из AniList, русские названия и описания — из Shikimori. Искать можно по-русски.
- Уведомления о сериях приходят, когда Android запускает фоновую проверку (обычно раз в несколько часов), и сразу при открытии приложения. Точное время до минуты без своего сервера не гарантируется.
- Чтобы обновить приложение после правок, замени файлы на GitHub и в `sw.js` увеличь номер версии в названиях кэша (например, `v2` → `v3`), чтобы телефон подхватил новую версию.
